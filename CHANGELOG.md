# Changelog

## 0.1.0 (2026-10-22)

First release.

- Chrome extension (Manifest V3) that records clicks as steps, using pre-captured frames so each step shows the page before the click.
- Browser editor: reorder, tooltips, draggable hotspots, text cards, zoom, blur, accent color and a final call-to-action.
- Export as a single HTML file, a website folder (.zip) with an iframe snippet, or a project file.
- Standalone player under 4 KB gzipped, keyboard and screen-reader friendly.
- End-to-end test that drives the real extension in Chrome for Testing.
